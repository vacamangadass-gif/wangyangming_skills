## 反复出现的核心论点（≥3次）

### 1. 心即理
- **出处**：《传习录》上卷（徐爱录）、《传习录》中卷书信、《大学问》
- **核心表述**：心外无理，心外无物，心外无事。圣人之道，吾性自足。
- **反复程度**：贯穿《传习录》全书，是阳明心学的逻辑起点，龙场悟道的核心结论。

### 2. 知行合一
- **出处**：《传习录》上卷、中卷、下卷；《大学问》；书信多处
- **核心表述**：未有知而不行者，知而不行，只是未知。知是行之始，行是知之成。
- **反复程度**：《传习录》中出现频率最高的命题，贯穿早中晚期思想。

### 3. 致良知
- **出处**：《传习录》中卷（晚年书信）、《大学问》、《传习录》下卷
- **核心表述**：致吾心之良知于事事物物。良知是天理之昭明灵觉处。
- **反复程度**：王阳明晚年（约50岁后）将其定为心学"一语之教"，视为毕生学问的最终归宿。

### 4. 万物一体之仁
- **出处**：《大学问》、《传习录》下卷、《拔本塞源论》
- **核心表述**：大人者，以天地万物为一体者也。见孺子入井，必有怵惕恻隐之心。
- **反复程度**：《大学问》开篇即立此论，《传习录》多处呼应，是其仁学的宇宙论基础。

### 5. 格物即正心（格心之非）
- **出处**：《传习录》上卷、中卷书信、《大学问》
- **核心表述**：格物者，格其心之物也；格其意之物也。天下之物本无可格者，格物之功只在身心上做。
- **反复程度**：针对朱熹"格物穷理"的持续批判与重构，贯穿全书。

## 自创术语与概念

### 良知（liángzhī）
| 维度 | 内容 |
|------|------|
| **传统来源** | 出自《孟子》："人之所不学而能者，其良能也；所不虑而知者，其良知也。" |
| **朱熹诠释** | 良知是道德认知能力，需通过格物穷理、读书积累来扩充。 |
| **王阳明诠释** | 良知即天理之昭明灵觉，是心的本体，人人先天具足，无需外求。良知即是非之心，即善恶判断的直觉能力。"致良知"是将此先天良知推致于事事物物，而非向外学习获得。 |
| **关键差异** | 朱熹：良知需后天培养 → 王阳明：良知先天自足，只需"致"（推扩、擦亮），去除私欲遮蔽即可。 |

### 格物（géwù）
| 维度 | 内容 |
|------|------|
| **传统来源** | 出自《大学》八条目："致知在格物" |
| **朱熹诠释** | 格物即穷究事物之理，通过观察外在事物积累知识，达到对天理的认识（即"即物穷理"）。 |
| **王阳明诠释** | 格物即"格心之非"，格去心中不正之念，使心恢复本体之正。物即意之所在，格物是在意念发动处做正念功夫，而非向外穷究事物。 |
| **关键差异** | 朱熹：向外 → 王阳明：向内。格竹子之理（朱熹路径）→ 格心中私欲（阳明路径）。 |

### 心即理（xīn jí lǐ）
| 维度 | 内容 |
|------|------|
| **程朱立场** | "性即理"——理是客观存在于天地万物中的规则，心只是认知工具，需通过格物才能认识外在之理。 |
| **王阳明立场** | 心外无理，心外无物。理不在外物，就在吾心。龙场悟道："圣人之道，吾性自足，向之求理于外者误也。" |
| **关键差异** | 理的位置：外在客观（朱熹）→ 内在主体（王阳明）。 |

### 知行合一（zhī xíng hé yī）
| 维度 | 内容 |
|------|------|
| **一般理解** | 理论与实践相结合。 |
| **王阳明诠释** | 知与行本是一体，真知必然导致行动；若知而不行，只是"未知"，是假知。知是行之始，行是知之成。强调的是感知与反应的即时统一，而非先知后行的两步骤。 |
| **关键差异** | 不是"先知后行"，而是"知行本一"——真正的道德认知与道德行动在本质上不可分割。 |

### 四句教（sì jù jiào）
- **原文**：无善无恶心之体，有善有恶意之动，知善知恶是良知，为善去恶是格物。
- **出处**：《传习录》下卷，天泉证道（王阳明晚年与弟子王畿、钱德洪的讨论）
- **意义**：对心学体系的最简洁总结，涵盖心体、意动、良知、格物四个层次。

## 著作思想演变脉络

```
早期（龙场悟道前）：学习程朱理学，格竹失败，质疑"向外求理"
        ↓
龙场悟道（1508年，37岁）：悟"心即理"，确立心学基础
        ↓
中期（1509-1520年代）：提出"知行合一"，讲学传播，《传习录》上卷形成
        ↓
晚期（1520年代后）：提出"致良知"为心学一贯宗旨，写《大学问》，天泉证道立"四句教"
```
