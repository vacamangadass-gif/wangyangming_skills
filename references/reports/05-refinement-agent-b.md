## 任务2：角色扮演规则可操作性评审

### 清晰可执行的规则

| 规则 | 可操作性 | 说明 |
|------|---------|------|
| 用心学核心镜片分析问题 | ✅ 清晰 | 三个镜片明确（心即理/知行合一/致良知） |
| 表达风格：断言+反问+类比 | ✅ 清晰 | 有具体比例和标志性句式模板 |
| 遇到事实问题先WebSearch | ✅ 清晰 | Step 1分类表明确了触发条件 |
| Step 2三个分析维度 | ✅ 清晰 | 心即理/知行合一/致良知维度各有具体问题 |

### 模糊规则（精炼前存在的问题）

#### 问题1：推导 vs 编造边界不清（已修复）

**原文**：「不编造王阳明未说过的话，但可以用他的思维框架推导新问题」

**问题**：什么算"推导"，什么算"编造"？边界模糊，执行时容易产生歧义。

**精炼后**：
```
不编造王阳明未说过的话，但可以用他的思维框架推导新问题。
推导边界：若王阳明有明确立场（有原文或历史记录），直接引用；
若无，则说明"以心学框架推导"，不伪装成历史事实
```

**状态**：✅ 已应用到SKILL.md

---

#### 问题2：Step 3"心中贼"无条件触发机械

**原文**：「指出"心中贼"（内在障碍）比"山中贼"（外在障碍）更难破」

**问题**：这条规则要求每次回答都指出"心中贼"，但并非所有问题都有"心中贼"的分析角度（如纯事实性问题、技术问题）。无条件触发会导致回答机械化。

**建议改为**：
```
若问题涉及行动障碍或决策困境，指出"心中贼"（内在障碍）比"山中贼"（外在障碍）更难破；
若为纯事实或技术问题，跳过此步骤
```

**状态**：⚠️ 建议应用，未强制执行（不影响核心功能）

---

#### 问题3：WebSearch规则与Step 1轻微重复

**原文（角色扮演规则）**：「遇到需要事实的问题，先用WebSearch获取真实信息，再用心学框架分析」

**原文（Step 1）**：「需要事实的问题 → 先研究再回答（Step 2）」

**问题**：两处都说了同一件事，但表述不完全一致，可能造成混淆。

**建议**：角色扮演规则中的WebSearch说明可简化为「详见回答工作流Step 1-2」，避免重复。

**状态**：⚠️ 建议应用，属于轻微优化
