# 一手来源 · 王阳明原典

---

## 《传习录》（Instructions for Practical Living）

| 项目 | 内容 |
|------|------|
| 性质 | 弟子辑录的语录、书信与问答集，共335条 |
| 结构 | 上卷（徐爱录，1518年刊）/ 中卷（书信为主，1524年）/ 下卷（身后编） |
| 核心内容 | 心即理、知行合一、致良知、格物新解、四句教 |
| 英译本 | Wing-tsit Chan（陈荣捷）译，*Instructions for Practical Living*，1963年，Columbia University Press |
| 重要章节 | 徐爱录（心即理、知行合一）；陆澄录（种树比喻、在事上磨）；天泉证道（四句教） |

---

## 《大学问》（The Great Learning）

| 项目 | 内容 |
|------|------|
| 性质 | 哲学论文，对《大学》的重新诠释 |
| 成书时间 | 晚年，1527年出征广西前夜由弟子钱德洪记录 |
| 核心内容 | 万物一体之仁；"大人者，以天地万物为一体者也" |
| 地位 | 心学入门纲领，系统阐发"万物一体"的宇宙论基础 |

---

## 《王文成公全书》（Complete Works）

| 项目 | 内容 |
|------|------|
| 性质 | 王阳明全集，身后编 |
| 结构 | 共38卷，含传习录、文录（奏疏、书信）、别录（诗文）、年谱 |
| 重要文献 | 《答顾东桥书》（系统阐发知行合一）；《拔本塞源论》（批判功利化学风）；《南赣乡约》（治理实践） |

---

## 《年谱》

| 项目 | 内容 |
|------|------|
| 性质 | 弟子编撰的传记资料 |
| 核心记录 | 龙场悟道原文："圣人之道，吾性自足，向之求理于外者误也" |
| 地位 | 了解王阳明生平与思想演变的基础文献 |

---

## 王阳明诗文

| 作品 | 内容 | 哲学意义 |
|------|------|---------|
| 龙场悟道诗 | "人人自有定盘针，万化根源总在心。却笑从前颠倒见，枝枝叶叶外头寻。" | 心即理的诗意表达 |
| 《月夜二首》 | "肯信良知原不昧，从他外物岂能撄。" | 良知如月，私欲如云 |
| 12岁早期诗 | "山近月远觉月小，便道此山大于月。若人有眼大如天，还见山小月更阔。" | 早年质疑相对视角的哲学思维 |
| 临终遗言 | "此心光明，亦复何言。" | 心学一生的最终总结 |
