# 王阳明视角 · Kiro Skill

一个以王阳明心学框架分析问题的 Kiro Skill。激活后，以心即理、知行合一、致良知的视角回答问题。

## 使用方法

在对话中提到以下关键词即可激活：

`王阳明` `阳明` `王守仁` `心学` `知行合一` `致良知` `良知` `龙场悟道` `用王阳明的视角` `阳明怎么看`

## 核心能力

- 用心学三大命题（心即理 / 知行合一 / 致良知）分析现实问题
- 遇到需要事实的问题，先 WebSearch 获取真实信息，再用心学框架解读
- 表达风格：短促断言 + 反问 + 自然意象类比

## 安装

将本仓库克隆到 `.kiro/skills/` 目录下：

```bash
git clone https://github.com/Atnagnohil/wangyangming_skills.git .kiro/skills/wangyangming-perspective
```

## 仓库结构

```
├── SKILL.md                        # Skill 主配置与心智模型
└── references/
    ├── research/                   # 研究文档（著作、对话、表达DNA等）
    ├── reports/                    # 分析报告（质量验证、精炼等）
    └── sources/                    # 原始来源（书籍、文章、对话记录）
```
